# Quick Task 260711-lc7 — YouTube: снять HTML из описания/заголовка

## Проблема

`publish` workflow 2026-07-11 упал на шаге YouTube для поста `unia-jul11-dvoe`:

```
HttpError 400 invalidDescription — "The request metadata specifies an invalid video description."
```

Причина: тело поста содержит Telegram-style HTML-ссылку
`<a href="https://uniaweb.ru/">ссылка</a>`. TG/VK её понимают, а YouTube
запрещает символы `<` / `>` в `snippet.description` (и в `snippet.title`).
`youtube_post.py` отдавал тело поста в описание как есть → отказ.

Последствие падения: шаг YouTube упал с exit 1 и оборвал workflow, поэтому
шаги «update plan status» и «commit moved files» были пропущены (TG/VK ушли).

## Задача

В `src/youtube_post.py` конвертировать HTML в плоский текст перед отправкой в
YouTube — так, чтобы `<`/`>` не попадали в title/description.

## Изменения

- `src/youtube_post.py`:
  - хелпер `strip_html()`:
    - `<a href="URL">текст</a>` → `текст: URL` (ссылка сохраняется как текст);
    - прочие теги (`<b>`, `<i>`, `<br>` …) снимаются, внутренний текст остаётся;
    - HTML-сущности декодируются (`html.unescape`);
    - страховка — остаточные `<`/`>` удаляются.
  - `derive_description()` и `derive_title()` пропускают текст через `strip_html`.
- `tests/test_publisher_filters.py`: 3 регресс-теста (включая точный кейс
  `unia-jul11-dvoe`).
