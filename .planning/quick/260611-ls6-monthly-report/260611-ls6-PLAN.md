# Quick Task 260611-ls6: Ежемесячный per-app отчёт

## Goal

5-го числа каждого месяца в TG-канал «Планировщик» прилетает отчёт за предыдущий
полный месяц по всем 5 продуктам студии (Centry, Diktum, Lucea, Лапуля, Unia)
с MoM-сравнением (текущий месяц vs предыдущий).

Структура отчёта идентична недельному (`hybrid_report`) за исключением:
- Заголовок: «App — отчёт за [месяц] [год]»
- Блок сторов: «данные сторов — в недельных отчётах»
- Блок 8: MoM вместо WoW

## Must-haves

- [ ] `src/monthly_report/__init__.py`
- [ ] `src/monthly_report/snapshot.py` — keyed by "YYYY-MM", max 13 months
- [ ] `src/monthly_report/render.py` — monthly render, word-based plain text, без эмодзи
- [ ] `src/monthly_report/cli.py` — entrypoint: calc previous month dates, gather, send
- [ ] `.github/workflows/monthly_report.yml` — cron "0 6 5 * *", same env секреты что store_metrics.yml (только нужные)
- [ ] Никакие существующие файлы не изменяются

## Architecture

### Date window
```
today = 2026-07-05
month_start = 2026-06-01
month_end   = 2026-06-30
```

### Data sources (все поддерживают произвольный date range)
- AppMetrica installs: `hybrid_report.appmetrica.fetch_installs(app_id, start, end)`
- AppMetrica activity: `hybrid_report.appmetrica.fetch_activity(app_id, start, end)`
- AppMetrica funnel: `hybrid_report.appmetrica.fetch_onboarding_funnel(...)`
- AppMetrica screens: `hybrid_report.appmetrica.fetch_top_screens(...)`
- Supabase Centry: `centry_funnel.supabase_src.fetch_funnel(start, end)`
- Supabase Diktum: `diktum_funnel.supabase_src.fetch_registrations(start, end)`
- Store installs: пропускаем (нет fetch_for_range в store модулях), render показывает заглушку

### Snapshot format
```json
{"2026-05": {"centry": {"am_installs_total": 450}, ...}}
```
File: `.metrics/monthly_snapshots.json`

### Reuse
- `PRODUCTS` из `hybrid_report.models`
- `ProductReport` dataclass — week_start/week_end держат month_start/month_end
- `WeekDelta.compute` для MoM delta (тот же расчёт)

## Tasks

## Constraints
- word-based, plain text, без эмодзи — как weekly report
- never-raises per источник (мягкая деградация)
- MONTHLY_DRY_RUN=1 / --dry-run для тестирования
- workflow cron: "0 6 5 * *" (9:00 МСК)
- commit snapshot через BOT_DISPATCH_PAT
